Касса экспедиторов — сайт на телефон и ПК.

==================================================
1. КАК РАБОТАЕТ ОНЛАЙН
==================================================
Не открывайте index.html двойным щелчком — так у каждого телефона своя касса.

Нужен адрес в интернете. Все заходят на ОДНУ ссылку.
Данные лежат в файле data.json на сервере.
Вы поставили QR — через несколько секунд водитель видит.
Он закрыл кассу — у вас в календаре «на руках».

Вход кассира: логин kassa   пароль 0000
Водителей добавляете в кабинете: имя + логин + пароль.

==================================================
2. БЫСТРЫЙ СТАРТ НА СВОЁМ ПК (чтобы проверить)
==================================================
На компьютере должен быть Python 3 (на Windows: python.org).

В папке kassa-web откройте командную строку и напишите:

    python server.py

Появится: Касса: http://127.0.0.1:8080
Откройте эту ссылку в браузере. Это ещё только ваш ПК.

Чтобы водители зашли с телефона СЕЙЧАС, без своего сайта:
1) Зарегистрируйтесь на ngrok.com, скачайте ngrok
2) В другом окне:  ngrok http 8080
3) Ngrok даст ссылку https://....ngrok-free.app
4) Эту ссылку киньте водителям. Пока запущены server.py И ngrok — сайт живой.
Компьютер не выключать.

==================================================
3. НОРМАЛЬНЫЙ САЙТ НАВСЕГДА
==================================================
Нужен хостинг, где крутится Python, не «только HTML».

Простой вариант — Render.com (бесплатный старт):
1. Зарегистрируйтесь на render.com
2. New → Web Service → залейте папку kassa-web (через GitHub или архив)
3. Start command:  python server.py
4. Render выдаст адрес вида https://kassa-xxxx.onrender.com
5. Эту ссылку ставите на телефоны: Chrome → «На экран Домой»

Платный простой в Казахстане / рядом:
Timeweb, Beget, AdminVPS — заказать VPS, залить папку, запустить:

    python3 server.py

Либо через systemd, чтобы не падало после перезагрузки.

==================================================
4. ЧТО СКАЗАТЬ ВОДИТЕЛЯМ
==================================================
Открой ссылку. Логин и пароль, которые выдал кассир.
Добавь на экран — как приложение.
Интернет нужен. Без сети касса не обновится.
